# 周期记录与双人关注

从底栏「周期」进入，记录经期开始、结束和每日身体感受，也可以补录历史。周期环和月历区分实际记录与预估；预估只用于个人参考，不作为避孕依据或医学判断。

## 分享与协作

- 账号不预设记录者或关注者。记录者可按需开放实际日期、预估和结构化感受；文字备注逐条决定是否分享。
- 伴侣代记需要授权。待确认的代记不计入正式历史和预估，记录者确认后才生效。
- 提醒按双方授权和接收偏好发送，锁屏默认只显示中性文案。撤回分享后接口不再返回相关数据。
- 本人可以导出自己的记录。本地完整备份包含健康数据；异地备份不上传周期健康表和相应通知。

服务端实现见 [`cycle2.py`](../cycle2.py)、[`cycle_engine.py`](../cycle_engine.py) 和 [`cycle2_collaboration.py`](../cycle2_collaboration.py)，前端见 [`web/cycle2.js`](../web/cycle2.js)。旧数据升级见[迁移说明](cycle-migration.md)。
